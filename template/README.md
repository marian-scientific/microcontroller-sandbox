## Summary
Extremely brief summary of the device. Include year introduced, size, packages available, cost, sources, specs, peripherals, and overall programming methodology.

### Minimal Toolchain
Document the minimal Linux toolchain for programming of the device. Include photos of the physical connections and specifically list any adapters/programmers used.

`use code blocks like this to document commands and code`

Document the details of any relevant software,  system specs, and OS of the computer used to program the device. For example: Linux kernel version, software versions, etc.

Take the simplest example below and literally walk step-by-step through the process of setting up the environment, compiling the code, flashing the device, and interacting with the device (if necessary, e.g. over serial port). It should be written so a moderately competent individual can follow your instructions to exactly replicate your results. You can assume they know how to install any required software, but specify the versions of any such software.
